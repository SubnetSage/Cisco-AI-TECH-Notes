# 📅 30-Day Exercise Guide: Cisco AITECH (810-110)
**Mastering Generative AI and Agentic Automation**

## Phase 1: Generative AI Foundations (Days 1 - 7)
*   **Day 1: Setup Local AI Env.** Install Ollama or LM Studio. Load a small model (Llama 3 or Mistral).
*   **Day 2: Model Comparisons.** Compare a cloud model (GPT-4o) with a local model on the same text summarization task.
*   **Day 3: Tokenization Practice.** Use an online tokenizer to see how different sentences are broken into tokens.
*   **Day 4: Context Window Test.** Feed a large document to a model and see where it starts losing coherence.
*   **Day 5: Introduction to RAG.** Manually search a PDF for a fact and include that fact in a prompt to see the model's accuracy improvement.
*   **Day 6: Vector Databases.** Research ChromaDB or Pinecone and their role in AI memory.
*   **Day 7: Model Selection.** Create a matrix comparing model speed, context window, and price for a fictional project.

## Phase 2: Prompt Engineering Mastery (Days 8 - 14)
*   **Day 8: Basic Prompting.** Practice creating prompts with clear Roles, Tasks, and Constraints.
*   **Day 9: Few-Shot Prompting.** Write a prompt with 3 examples of a specific output format (e.g., JSON schema).
*   **Day 10: Chained Prompting.** Write a sequence of prompts to generate a blog post (Research ➔ Outline ➔ Draft ➔ Edit).
*   **Day 11: Image Generation.** Use a diffusion model (DALL-E or Midjourney) to generate specific architecture diagrams.
*   **Day 12: Prompt Injection.** Try to safely "jailbreak" a model into revealing its system instructions.
*   **Day 13: Defensive Prompting.** Write a prompt that explicitly forbids the model from discussing sensitive topics.
*   **Day 14: Hallucination Hunting.** Deliberately prompt for fake facts and analyze why the model failed.

## Phase 3: Ethics, Security, and Data (Days 15 - 21)
*   **Day 15: AI Principles.** Draft a "Responsible AI" policy for a fictional company.
*   **Day 16: Privacy Check.** Identify sensitive PII in a sample dataset that must be redacted before sending to an LLM.
*   **Day 17: Misinformation Analysis.** Use an LLM to generate a fake news story and then identify the "tells."
*   **Day 18: EDA with AI.** Use an LLM (or ChatGPT Advanced Data Analysis) to find trends in a CSV file.
*   **Day 19: Data Preparation.** Write a Python script (with AI help) to clean and format a messy dataset.
*   **Day 20: Governance Review.** Research current AI regulations (e.g., EU AI Act) and their impact on developers.
*   **Day 21: Ethical Case Studies.** Review the "bias" in AI image generation for specific job roles.

## Phase 4: AI Development & Automation (Days 22 - 28)
*   **Day 22: AI for Debugging.** Feed a broken piece of code to an LLM and analyze its suggested fix.
*   **Day 23: Rapid Prototyping.** Use AI to generate a functional HTML/CSS mock-up for a dashboard.
*   **Day 24: AI Workflow Design.** Create a flowchart for an automated customer support bot.
*   **Day 25: Token Cost Management.** Calculate the cost of processing 1 million tokens across different providers.
*   **Day 26: Agent Architecture.** Sketch a design for an AI agent that can browse the web and book a flight.
*   **Day 27: Human-in-the-Loop.** Design a "Review/Approve" step for an AI-generated social media poster.
*   **Day 28: MCP Basics.** Research Model Context Protocol and how it bridges LLMs to local files.

## Phase 5: Agentic AI & Review (Days 29 - 30)
*   **Day 29: Agentic vs GenAI.** Write a comparison paper on when to use a simple LLM vs a multi-agent system.
*   **Day 30: Final Simulation.** Build a "Researcher Agent" using a tool like AutoGPT, CrewAI, or simple Python.
